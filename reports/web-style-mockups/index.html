A · Libro: the app as a household account book

  • Fraunces (serif) for headings, labels and the large numbers. Public Sans for UI text, IBM Plex Mono for amounts in rows so the euros line up in columns.
  • Warm neutrals (brown-black and paper white) replace the cold navy. Backgrounds still don't change with the accent preset.
  • No nested cards. Rows sit on dashed ledger lines, page titles get a double rule, and only the Balances side panel is a surface.
  • The fixed gold (#d9b56c) marks the active tab and active group. It's a fixed colour, not --secondary, because that variable changes with each preset.
  • The accent preset only drives buttons, links and the FAB.

B · Bloque: bold, graphic, colour as structure

  • One heavy grotesque typeface (Bricolage Grotesque) for everything. Big tight headings, 80px+ balance numbers.
  • No borders. Hierarchy comes from filled surfaces, large radii and colour blocks.
  • The accent preset becomes the identity: your balance hero and the "te deben" block are filled with --primary, so changing the preset changes the whole personality.
  • Group colours become solid tiles, and categories get a soft colour tile on each expense row.
  • Risk: with the Amber, Orange or Green presets the hero is a large mid-tone block. --text-on-accent handles contrast, but it's loud.

Shared in both: date-grouped activity, a "your balance" hero in group detail, the "te deben / debes" totals kept separate (never netted) on Grupos, coloured member avatars, one brand mark on desktop, and no gradients. The mockup data is invented. Fonts load from Google Fonts here; the real app would self-host them.
